# Computer Modern Serif web fonts

Downloaded unmodified from https://github.com/vsalvino/computer-modern at commit
`f55b094cc91a643fecde154bb7ddb6fd9fed1b54` (2025-03-11).
The repository documents conversion with FontForge from Computer Modern Unicode
sources at https://cm-unicode.sourceforge.io/.

In this website, the regular and bold files are named `cmu-serif-regular.woff2`
and `cmu-serif-bold.woff2`, and the license is named `LICENSE.txt`.
Only the filenames have changed; the file contents and hashes are unchanged.

- `CMUSerif-Roman.woff2`: regular upright, CSS weight 400; upstream path `fonts/CMUSerif-Roman.woff2`.
- `CMUSerif-Bold.woff2`: bold upright, CSS weight 700; upstream path `fonts/CMUSerif-Bold.woff2`.
- `LICENSE-CMU.txt`: exact upstream `LICENSE.txt`, including author copyright notices and SIL Open Font License 1.1.

Keep the license and copyright notices with the redistributed fonts. The OFL
permits embedding and redistribution and does not require documents using these
fonts to adopt the font license. No modifications or subsetting were performed.
